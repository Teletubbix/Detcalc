# Detcalc —— C 语言行列式计算器（≤20 阶）

支持：[r×k] * [k×r] 矩阵乘法后取行列式、任意维度序列连乘、一般 n×n 方阵行列式（高斯消元+部分主元）。
精确分数（有理数）运算、符号/正负号分析、复杂输入格式（分数/小数/科学计数、按行/文件输入）。

## 用法
```bash
make            # 构建 Detcalc
make run        # 交互式运行（输入 2 4 / 2 4 3 2 / n / 0 退出）
make test       # 自动测试
./Detcalc 2 4            # 命令行：算 [2x4]*[4x2] 的行列式（矩阵从 stdin 读）
./Detcalc 2 4 3 2 -o out # 连乘并导出到文件
./Detcalc 3              # 3x3 行列式
```
